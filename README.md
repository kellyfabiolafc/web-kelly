# Kawaii World

##   Descripción del proyecto

**Kawaii World** es una landing page inspirada en el universo de Sanrio y la estética japonesa *kawaii*.

Este proyecto tiene como finalidad desarrollar un sitio web visualmente atractivo, utilizando colores pastel, imágenes de personajes y elementos decorativos característicos de la cultura kawaii.

##  Objetivo

* Aplicar los conocimientos de **HTML5, CSS3 y JavaScript**.
* Utilizar etiquetas semánticas para organizar el contenido.
* Diseñar una interfaz atractiva, ordenada y adaptable a diferentes dispositivos.
* Implementar imágenes, tablas, enlaces y formularios.
* Practicar el control de versiones utilizando **Git y GitHub**.

##  Contenido del sitio web

* **Inicio:** presentación principal del mundo kawaii.
* **Personajes:** sección dedicada a personajes como Hello Kitty, My Melody, Kuromi y Cinnamoroll.
* **Colecciones:** galería de artículos y accesorios kawaii.
* **Información:** tablas con datos de personajes y categorías.
* **Contacto:** formulario para enviar mensajes.
* **Footer:** enlaces a redes sociales e información del sitio.

##  Tecnologías utilizadas

* **HTML5:** estructura y contenido de la página.
* **CSS3:** estilos, colores y diseño responsive.
* **JavaScript:** funcionalidades e interacciones.
* **Git:** control de versiones.
* **GitHub:** almacenamiento del repositorio.

##  Estructura del proyecto

* **css/** — contiene los estilos de la página.
* **js/** — contiene las funciones de JavaScript.
* **images/** — almacena las imágenes utilizadas.
* **test/** — carpeta destinada a pruebas.
* **index.html** — archivo principal del sitio web.
* **README.md** — documentación del proyecto.
* **.gitignore** — excluye la carpeta test del repositorio.
